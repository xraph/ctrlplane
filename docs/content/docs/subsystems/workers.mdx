Ctrl Plane uses background workers for tasks that run on a schedule: datacenter reconciliation, garbage collection, and the health check, telemetry and certificate passes. The `worker.Scheduler` manages their lifecycle.

## Worker interface

Every worker implements a simple interface:

```go
type Worker interface {
    Name() string
    Interval() time.Duration
    Run(ctx context.Context) error
}
```

`Interval()` controls how often the worker runs. Return `0` for event-driven workers that run once and exit.

## Scheduler

The scheduler manages a set of workers, starting them as goroutines and stopping them gracefully:

```go
scheduler := worker.NewScheduler()
scheduler.Register(myWorker)
scheduler.Register(anotherWorker)

// Start all workers
err := scheduler.Start(ctx)

// Stop with a 10-second grace period
err := scheduler.Stop(ctx)
```

When using `app.New()`, the scheduler is created and populated automatically. The five built-in workers are registered during `wireServices()`.

## Built-in workers

### Reconciler

Walks every datacenter and drives its bootstrap services forward: it installs the services the datacenter declares or a bootstrap hook contributes, retries the ones that failed, and retires the ones nobody wants any more. A broken datacenter doesn't stop the others. Instance drift correction is planned but not there yet.

**Default interval:** 60 seconds

### HealthRunner

A placeholder today. Health checks run when you call `health.Service.RunCheck`.

**Default interval:** 30 seconds (configurable via `Config.HealthInterval`)

### TelemetryCollector

A placeholder today. The metrics poller samples instance resources on its own schedule.

**Default interval:** 10 seconds (configurable via `Config.TelemetryFlushInterval`)

### GarbageCollector

Deletes orphaned instances, one tenant at a time: instances whose `ctrlplane.workload` label points at a workload that no longer exists and that are older than the grace period (15 minutes by default). It goes through `instance.Service.Delete`, so the provider tears the workload down and the usual events fire. One tenant failing doesn't stop the sweep.

**Default interval:** 5 minutes

### CertRenewer

A placeholder today.

**Default interval:** 12 hours

## Telemetry

The scheduler times every pass in `forge_ctrlplane_worker_run_duration_seconds`, labelled by worker name and result, and counts ticks it skipped because another replica leads. The reconciler and garbage collector start one root span per pass that has work to do, and the scheduler runs workers without the span of the context you started it with, so nothing they do lands in your boot trace. See [Observability](/docs/subsystems/observability).

## Custom workers

Register your own workers for application-specific tasks:

```go
type UsageReporter struct{}

func (w *UsageReporter) Name() string            { return "usage-reporter" }
func (w *UsageReporter) Interval() time.Duration  { return 5 * time.Minute }
func (w *UsageReporter) Run(ctx context.Context) error {
    // collect and report usage metrics
    return nil
}

scheduler.Register(&UsageReporter{})
```

## Lifecycle

Workers are started by `cp.Start(ctx)` and stopped by `cp.Stop(ctx)`. The context passed to `Start` is used as the parent context for all worker goroutines. When `Stop` is called, the context is cancelled and workers have 10 seconds to finish their current cycle.
